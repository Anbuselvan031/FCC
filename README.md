# Fahrenheit Cricket Club (FCC)

Official web portal and analytics dashboard for **Fahrenheit Cricket Club** (Coimbatore, Tamil Nadu, India — Established 24 August 2023).

- **CricHeroes Team ID**: `4978895`
- **Official Instagram**: [@fahrenheit_cricket_club](https://www.instagram.com/fahrenheit_cricket_club)
- **Official Email**: Fahrenheitcricketclub@gmail.com

---

## Features
- **Team Roster**: Verified player profiles, batting/bowling statistics, and career leaderboards.
- **Match Center**: Recent matches, live scorecard views, and upcoming fixtures.
- **Club Records & Leaderboards**: Batting and bowling leaders, match milestones, and team achievements.
- **Gallery**: Memories and authentic team photos from the field.
- **Admin Portal**: Squad, match, stats, and gallery management.

---

## Tech Stack
- **Frontend**: React 18, Vite 5, Tailwind CSS 3, Lucide React
- **Backend**: Node.js, Express, MongoDB Atlas, JWT Authentication
- **Routing**: React Router DOM v6

---

# Start frontend
